# Capital Excavation agent instructions

Before doing any work, read `docs/CX-DELIVERY-GUIDE.md` completely. Then read
`docs/PROJECT-INSTRUCTIONS.md`, the repository README when present, and the
issue or request that defines the work.

The governed delivery guide controls conflicts. Project instructions may add
project-specific constraints but may not weaken the governed contract.

Do not edit, delete, rename, replace, or work around these governed files:
`AGENTS.md`, `CLAUDE.md`, `docs/CX-DELIVERY-GUIDE.md`, or
`.github/CODEOWNERS`. Request governance changes in
`CapitalExcavation/team-collab`.

Keep changes inside the requested project scope. Do not modify application
behavior to conceal an identity, network, broker, deployment, or vendor-access
failure. Preserve existing user work and report the first failing boundary with
evidence.
